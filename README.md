## Core Patterns

- **Substance First Refactoring**: Substance-First Gate: forbid linting, docstring beautification, and cosmetic renames until tests compile and pass.
- **Practical Application**: Blocking 'coat-of-paint' refactoring on broken or unverified code.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
